This is an example post. It is marked `draft: true`, so it shows up while running `npm run dev` but not on the published site.

To write a new post, add a Markdown file to `src/content/blog/`. The file name becomes the URL, so `my-first-post.md` is published at `/blog/my-first-post/`.

## What Markdown supports

Headings, **bold**, *italic*, [links](https://astro.build), lists, images and code blocks with syntax highlighting:

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"
```

> Quotes work too.
